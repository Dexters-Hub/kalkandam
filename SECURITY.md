# Security

If you find a security problem in Kalkandam, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Dexters-Hub/kalkandam/security/advisories/new) rather than in a public issue.

Please include what you found, how to reproduce it, and what someone could do with it. I'll reply as soon as I can.

The site is static apart from a small Cloudflare Worker (`worker/index.js`) that counts visits and turns the contribution form into GitHub issues.
